# swamp-test-evidence-validator

[swamp](https://swamp.club) extension `@mgreten/test-evidence-validator` —
validates a parsed test result for internal consistency and pins the evidence
to an immutable Git commit and branch.

📖 **Extension documentation:** [extensions/models/README.md](extensions/models/README.md)

📦 **Install:** `swamp extension pull @mgreten/test-evidence-validator`

## Repository layout

This repository is a swamp workspace (its own `.swamp.yaml` repo). The
publishable extension lives under [extensions/models/](extensions/models/).
